# 全台道路即時路況查詢站 使用說明與維運手冊

本系統為專為行動裝置與桌面瀏覽器設計的高效能即時路況查詢站，涵蓋全台國道、省道快速公路、一般省道主支線，並提供國道五號雪山隧道專屬分道時速與進洞智慧推薦。

* **線上公開網址（GitHub Pages）**：[https://cv1706.github.io/taiwan-traffic-live/](https://cv1706.github.io/taiwan-traffic-live/)
* **GitHub 獨立儲存庫**：[https://github.com/cv1706/taiwan-traffic-live](https://github.com/cv1706/taiwan-traffic-live)

## 一、 連線與存取方式

### 1. 線上雲端存取（推薦，手機免連區網）
直接以手機或電腦瀏覽器開啟：
* **正式網址**：`https://cv1706.github.io/taiwan-traffic-live/`
* **手機主畫面捷徑（PWA 體驗）**：
  * **iOS (Safari)**：點擊瀏覽器下方「分享」按鈕 → 選擇「加入主畫面」。
  * **Android (Chrome)**：點擊右上角選單「⋮」 → 選擇「加到主螢幕」或「安裝應用程式」。

### 2. 電腦本機與區域網路存取
* **本機存取**：`http://localhost:8089` （或 `http://localhost:8089/index.html`）
* **手機區網存取**（需連同一個 Wi-Fi）：`http://192.168.1.50:8089`
* **本機伺服器啟動指令**：
  ```powershell
  python -m http.server 8089 --directory "c:\Users\yangk\.gemini\antigravity\scratch\Obsidian-Vault\taiwan-traffic-live"
  ```
* **防火牆放行指令**（若手機無法連線時於 PowerShell 執行）：
  ```powershell
  New-NetFirewallRule -DisplayName "Allow Traffic Web Server 8089" -Direction Inbound -LocalPort 8089 -Protocol TCP -Action Allow
  ```

## 二、 核心功能操作指南

### 1. 首頁：全台道路高密度索引矩陣
* **📍 附近路況（GPS 持續動態追蹤）**：點擊搜尋欄右側「📍 附近」按鈕，系統透過 `watchPosition` 啟用微秒級硬體 GPS 連續監聽，自動依車輛移動即時計算全台 34 條道路之直線距離並置頂排序，顯示最近交流道與精確公里數。
* **雪山隧道一鍵直達**：頂部置頂深藍橫幅「🏔️ 國 5・雪山隧道專區」，點擊秒進雪隧微觀分道時速與進洞決策卡。
* **關鍵字即時檢索**：輸入道路編號（如「國 1」、「台 61」）或地名／交流道（如「頭份」、「竹南」、「林口」）即時過濾。
* **系統分類標籤**：一鍵切換「全部 (34)」、「國道 (10)」、「快速公路 (14)」、「主要省道 (10)」。
* **三欄微徽章瓦片矩陣**：單屏完整呈現 34 條以上路線，大幅減少上下滾動。

### 2. 道路內頁：智慧動態導航與極簡路況流
* **📍 當前交流道自動垂直置中（Auto-Centering）**：取得 GPS 定位進入任意路線後，系統自動識別距離最近之交流道，並於 0.1 秒內平滑滾動（Smooth Scroll）至視窗垂直正中央，並套用藍色呼吸光暈與「📍 目前位置」標籤。
* **📍 頂部三站式 GPS 導航橫幅（GPS Navigation Banner）**：頁面頂部直覺呈現三站脈絡：
  * **前一站（上游回堵速覽）**：檢驗後方剛通過路段之即時車速。
  * **當前交流道**：顯示目前位置、距交流道之實體距離與即時車速。
  * **下一站（即將抵達出口）**：預判前方即將抵達出口之通暢程度。
* **➡️ 「僅看前方」動態過濾模式（Forward-Only Dynamic Pruning）**：
  * 點擊頂部「➡️ 僅看前方」按鈕，系統自動隱藏行進方向已經駛過之所有交流道。
  * 當車輛持續向南（或向北）行駛通過新交流道時，已通過之交流道自動自頂部隱藏，清單第一列永遠保持為「當前交流道」，下方依序展開前方未通過路段。
* **🌐 「全線 (自動置中)」模式**：保留全線交流道脈絡，車輛換站時自動平滑滾動至新交流道中央。
* **📌 頂部吸頂凍結面板（Sticky Header）**：在詳情頁瀏覽或捲動測站清單時，頂部控制列、GPS 導航卡、警示/決策卡與時速圖例列全程凍結固定在螢幕上方，操作不中斷。
* **🔀 系統交流道交會路網快速跳轉（JCT Quick Jump）**：所有交會於其他國道、快速公路或主要省道之系統交流道（如「大華系統 (接台62)」、「汐止系統 (接國3)」、「五股交流道 (接台64/65)」），自動解析並生成帶有官方分類色標之可點擊按鈕（如 `[接台62 ↗]`、`[接國3 ↗]`），點擊即可秒級切換至交會道路之即時路況。
* **🛡️ 手動滑動防干擾保護（Scroll Protection）**：駕駛或副駕手動滑動檢視其他路段時，系統自動鎖定畫面 3.5 秒不強制回拉，停止滑動後自動恢復跟隨。
* **💡 螢幕長亮支援（Screen Wake Lock API）**：啟動 GPS 追蹤時自動保持手機螢幕常亮，防止駕駛途中螢幕休眠。
* **方向切換**：頂部一鍵切換「南下／北上」或「東向／西向」，系統自動反轉里程排程順序與前後出口導航方向。
* **全線純淨單一時速**：一般露天公路全面隱藏多車道細碎標籤，僅顯示清晰醒目之斷面平均時速；雪山隧道等長隧道則完整保留分道時速。

### 3. 雪山隧道微觀專區與進洞決策卡
* **全線 (12.9km) 雙車道均速計算**：動態彙整隧道內 5 個偵測站點，即時計算「內側全程均速」與「外側全程均速」。
* **通過時間量化**：依即時均速換算全線預估通過時間（精確至 0.1 分鐘）。
* **進洞車道智慧推薦**：
  * 若內側均速顯著較快（≥ 4 km/h）：推薦「👉 建議走內側車道（省約 X 分鐘）」。
  * 若外側均速顯著較快（≥ 4 km/h）：推薦「👉 建議走外側車道（省約 X 分鐘）」。
  * 若速差 < 4 km/h：提示「⚖️ 雙車道均速相當，依現場排隊長度選擇即可」。
* **微觀各站點對比**：提供各偵測點（15.3k、18.5k、21.0k、24.2k、27.8k）精簡雙車道時速。

## 三、 數據指標與顏色圖例

### 1. 車速色階標準
| 時速區間 | 顏色標示 | 車流狀態定義 |
| :--- | :--- | :--- |
| **80+ km/h** | 綠色 | 順暢（自由行車流） |
| **60 – 79 km/h** | 黃色 | 微慢（車流漸增） |
| **40 – 59 km/h** | 橘色 | 車多（行車緩慢） |
| **20 – 39 km/h** | 紅色 | 壅塞（嚴重回堵） |
| **0 – 19 km/h** | 紫色 | 紫爆（車流停滯） |

### 2. 資料品質與狀態標籤
* **60 秒自動更新**：頂部計時器每分鐘自動重新輪詢並更新數值。
* **⚠️過期（黃色標籤）**：資料收集時間與當前時間差超過 3 分鐘，提醒駕駛數據具延遲。
* **✕離線（灰色標籤）**：該偵測點感測器維修中或斷訊無回傳，避免誤導。

### 3. 專題名詞：車道佔有率（Occupancy）
* **定義**：在 1 分鐘內，車輛本體壓過路面感測線圈的總時間佔總時間的百分比。
* **判讀標準**：
  * **0% – 15%**：車流稀疏，極度順暢。
  * **15% – 25%**：穩定車流，正常行駛。
  * **25% – 35%**：車多接近道路飽和容量。
  * **35% 以上**：走走停停或完全靜止停滯。
