# 全台道路即時路況查詢站 使用說明與維運手冊

本系統為專為行動裝置與桌面瀏覽器設計的高效能即時路況查詢站，涵蓋全台國道、省道快速公路、一般省道主支線，並提供國道五號雪山隧道專屬分道時速監測。

---

## 一、 快速啟動與連線方式

### 1. 電腦本機存取
於瀏覽器網址列直接輸入：
* `http://localhost:8089` （或 `http://localhost:8089/index.html`）

### 2. 手機區網連線步驟
當電腦與手機連線於同一個 Wi-Fi 路由器時：
1. 確認電腦區網 IP（例如：`192.168.1.50`）。
2. 在手機瀏覽器（Safari、Chrome 等）網址列輸入：
   ```text
   http://192.168.1.50:8089
   ```
3. 若手機無法開啟，請以系統管理員身分在電腦 PowerShell 執行防火牆放行指令：
   ```powershell
   New-NetFirewallRule -DisplayName "Allow Traffic Web Server 8089" -Direction Inbound -LocalPort 8089 -Protocol TCP -Action Allow
   ```

### 3. 伺服器啟動與終止指令
* **啟動指令（進入專案目錄）**：
  ```powershell
  python -m http.server 8089 --directory "c:\Users\yangk\.gemini\antigravity\scratch\Obsidian-Vault\taiwan-traffic-live"
  ```
* **背景停止指令**：
  ```powershell
  Get-Process -Name python -ErrorAction SilentlyContinue | Stop-Process -Force
  ```

## 二、 核心功能操作指南

### 1. 首頁：全台道路高密度索引矩陣
* **雪山隧道一鍵直達**：頂部置頂藍色橫幅「🏔️ 國 5・雪山隧道專區」，點擊秒進雪隧微觀分道時速。
* **關鍵字搜尋**：支援輸入道路編號（如「國 1」、「台 61」）或地名（如「合歡山」、「林口」）即時篩選。
* **系統分類標籤**：可切換「全部」、「國道」、「快速公路」、「省道」。
* **三欄微徽章按鈕**：單屏呈現 34 條以上路線，大幅減少上下滾動。

### 2. 道路內頁：雙向單行路況流
* **方向切換**：頂部一鍵切換「南下／北上」或「東向／西向」，系統自動反轉里程排程順序。
* **全線／雪隧切換**：國道 5 號支援切換「全線總覽」與「僅看雪隧內」。
* **單行極簡條（高度 36 px）**：單屏直接閱覽 12–15 個連續交流道斷面時速。
* **即時事件 Alert**：施工、事故、紫爆回堵直接以單行橫幅置頂提示。

### 3. 雪山隧道微觀專區與進洞決策卡
* **全線 (12.9km) 雙車道均速計算**：動態彙整隧道內 5 個偵測站點，即時計算「內側全程均速」與「外側全程均速」。
* **通過時間量化**：依即時均速換算全線預估通過時間（精確至 0.1 分鐘）。
* **進洞車道智慧推薦**：
  * 若內側均速顯著較快（≥ 4 km/h）：推薦「👉 建議走內側車道（省約 X 分鐘）」。
  * 若外側均速顯著較快（≥ 4 km/h）：推薦「👉 建議走外側車道（省約 X 分鐘）」。
  * 若速差 < 4 km/h：提示「⚖️ 雙車道均速相當，依現場排隊長度選擇即可」。
* **微觀各站點對比**：提供各偵測點（15.3k、18.5k、21.0k、24.2k、27.8k）精簡雙車道時速。

## 三、 數據指標與顏色圖例

### 1. 車速色階標準
| 時速區間 | 顏色標示 | 車流狀態定義 |
| :--- | :--- | :--- |
| **80+ km/h** | 綠色 | 順暢（自由行車流） |
| **60 – 79 km/h** | 黃色 | 微慢（車流漸增） |
| **40 – 59 km/h** | 橘色 | 車多（行車緩慢） |
| **20 – 39 km/h** | 紅色 | 壅塞（嚴重回堵） |
| **0 – 19 km/h** | 紫色 | 紫爆（車流停滯） |

### 2. 資料品質與狀態標籤
* **60 秒自動更新**：頂部計時器每分鐘自動重新輪詢並更新數值。
* **⚠️過期（黃色標籤）**：資料收集時間與當前時間差超過 3 分鐘，提醒駕駛數據具延遲。
* **✕離線（灰色標籤）**：該偵測點感測器維修中或斷訊無回傳，避免誤導。

### 3. 專題名詞：車道佔有率（Occupancy）
* **定義**：在 1 分鐘內，車輛本體壓過路面感測線圈的總時間佔總時間的百分比。
* **判讀標準**：
  * **0% – 15%**：車流稀疏，極度順暢。
  * **15% – 25%**：穩定車流，正常行駛。
  * **25% – 35%**：車多接近道路飽和容量。
  * **35% 以上**：走走停停或完全靜止停滯。
